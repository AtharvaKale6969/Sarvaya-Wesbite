# Sarvaya Holdings Private Limited Website

Corporate group website for Sarvaya Holdings Private Limited, built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

The site runs at http://localhost:5173.

## Build

```bash
npm run build
```

The production build is written to `dist/`.

## Where to edit content

- `src/data/content.js`: group details, navigation, values and the four businesses
- `src/data/sectors.js`: sector stories and company profiles on the Our Businesses page
- `src/data/images.js`: image URLs (currently Unsplash placeholders, to be replaced with approved photography)
- `src/pages/`: one file per page
